# Folder Guide

## frontend

Next.js App Router application using TypeScript, React Query, React Hook Form, Zod, Tailwind CSS v4,
and reusable shadcn-style components.

## backend

FastAPI application with Pydantic models, SQLAlchemy sessions, Alembic migrations, and REST routing.

## ai

Python workspace for model inference and ML support code.

## database

Design notes and data architecture documentation.

## docker

Container build context and Compose orchestration.

## docs

Long-form architecture and implementation notes.

## .github

CI workflows for linting, formatting, and type validation.
